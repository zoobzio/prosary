# @prosary/core

The runtime of prosary. It reads a document against a contract and hands each
node to a renderer.

[`@prosary/schema`](../schema) has the contract and the runtime guards. The
[`prosary`](../prosary) package re-exports `@prosary/core` and
`@prosary/schema`.

## Install

```sh
pnpm add @prosary/core
```

The package has no API yet.
