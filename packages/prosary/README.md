# prosary

The public package of prosary. It re-exports the runtime,
[`@prosary/core`](../core), and the contract, [`@prosary/schema`](../schema),
under one import.

## Install

```sh
pnpm add prosary
```

[`@prosary/kit`](../kit) builds a prose package from its config. Install the
kit as a separate package.

## Entry points

| Import    | Re-exports                                                 |
| --------- | ---------------------------------------------------------- |
| `prosary` | [`@prosary/core`](../core), [`@prosary/schema`](../schema) |

The package has no API yet. Subpaths join this table as they are written.
